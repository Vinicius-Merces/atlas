# Codex Workflow: Feature Delivery

1. Load project memory.
2. Clarify product outcome and acceptance criteria.
3. Map repository impact.
4. Select implementation specialists.
5. Implement the smallest coherent change.
6. Run relevant tests and static checks.
7. Run architecture, security, UX, and QA reviews as applicable.
8. Update documentation and memory.
9. Report evidence and remaining risks.
