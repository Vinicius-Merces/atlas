# Codex Session Bootstrap

Before continuing project work:

1. Read `/AGENTS.md`.
2. Read `/.atlas/continuity/resume-packet.json` when present.
3. Read the referenced project and session briefs.
4. Read relevant `.claude/memory/` files.
5. Inspect repository status.
6. Continue only from validated repository evidence.

For product work through a shared ATLAS toolkit, select the product root explicitly
and use `project_memory.py start`. Do not load or update the toolkit checkout's
continuity as though it belonged to the product. Follow
`docs/project-local-memory-guide.md` for initialization and closeout.
