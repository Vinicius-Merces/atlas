# Codex Task Protocol

## 1. Interpret

Identify the requested outcome, constraints, and risk.

## 2. Load context

Read relevant memory, architecture, repository, contracts, and prior decisions.

## 3. Select roles

Use the smallest sufficient set of ATLAS roles.

## 4. Execute

Follow the closest canonical or mapped workflow.

## 5. Validate

Run relevant tests, checks, and review gates.

## 6. Synchronize knowledge

Update stable project memory or documentation when behavior or constraints change.

## 7. Report evidence

Use the execution evidence format.
