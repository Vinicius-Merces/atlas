# Shared Parallel Execution Protocol

1. Create workstreams from a validated task envelope.
2. Assign dependencies and supported runtimes.
3. Declare resource claims.
4. Detect and resolve blocking conflicts.
5. Execute each workstream independently.
6. Produce workstream checkpoints and evidence.
7. Validate merge readiness.
8. Reconcile outputs.
9. Run combined validation and final reviews.
