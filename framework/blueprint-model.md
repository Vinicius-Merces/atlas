# Blueprint Model

A blueprint is a reusable starting architecture for a class of project.

## Blueprint contents

- Project purpose
- Recommended architecture
- Suggested agents
- Required memory
- Default workflows
- Quality gates
- Risks
- Starter files
- Adoption checklist

## Blueprint principles

- Blueprints are starting points, not rigid templates.
- Product-specific decisions remain outside generic blueprints.
- Security, privacy, and operational requirements remain proportional to risk.
- Blueprints should explain trade-offs.
- Unsupported assumptions must be visible.
