# Platform Model

ATLAS defines a platform as a reusable technical foundation that reduces
duplication and improves delivery consistency across products and teams.

## Platform responsibilities

- Shared infrastructure
- Deployment and environment standards
- Service and application templates
- Developer tooling
- Identity and access foundations
- Observability foundations
- Integration patterns
- Repository standards
- Golden paths

## Platform principles

- Build platforms around recurring needs.
- Treat developer experience as a product concern.
- Prefer self-service with safe defaults.
- Make ownership explicit.
- Preserve escape hatches for justified exceptions.
- Measure adoption, reliability, and friction.
- Avoid centralizing product-specific logic.

## Golden path

A golden path is a recommended, supported route for building and operating a
class of system. It should be documented, observable, versioned, and optional
when a justified alternative exists.
