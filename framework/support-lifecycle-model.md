# Support Lifecycle Model

ATLAS classifies runtime and framework support explicitly.

## Support states

### Stable

Validated, documented, and expected to remain compatible.

### Beta-supported

Usable for real projects with documented limitations and active feedback.

### Experimental

Available for evaluation, but contracts or integrations may change.

### Deprecated

Still present during a migration window.

### Unsupported

No compatibility or maintenance commitment.

## Support obligations

A supported capability should provide:

- Ownership
- Documentation
- Compatibility status
- Validation evidence
- Known limitations
- Upgrade guidance
- Deprecation path
