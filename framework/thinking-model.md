# Thinking Model

ATLAS uses a repeatable reasoning sequence.

## 1. Understand

- What is the requested outcome?
- Who is affected?
- What does success look like?

## 2. Gather context

- Existing architecture
- Relevant memory
- Active contracts
- Existing skills and components
- External constraints

## 3. Identify risks

- Regression
- Data loss
- Security
- Performance
- Accessibility
- Operational complexity

## 4. Compare options

Each option should be evaluated by:

- Correctness
- Complexity
- Compatibility
- Reversibility
- Cost
- Maintenance burden

## 5. Plan

Define:

- Scope
- Sequence
- Ownership
- Validation
- Rollback strategy

## 6. Execute

Make the smallest coherent change that satisfies the accepted plan.

## 7. Validate

Test behavior, integration points, edge cases, and quality gates.

## 8. Document

Record what changed, why, and how future maintainers should reason about it.
