# Memory Taxonomy

ATLAS divides memory into six categories.

## 1. Business memory

Business rules, terminology, target users, product boundaries, and commercial
constraints.

## 2. Architecture memory

System boundaries, service ownership, data flow, technical constraints, and
approved patterns.

## 3. Integration memory

External systems, APIs, authentication methods, payload expectations, and
failure behavior.

## 4. Brand memory

Voice, visual principles, interaction tone, typography, colors, and content
constraints.

## 5. Security memory

Trust boundaries, sensitive data classifications, permission models, and
security requirements.

## 6. Operational memory

Deployment rules, monitoring expectations, environments, incident procedures,
and rollback constraints.

## Selection rule

Load only the memory categories relevant to the current task. Excessive context
reduces precision and increases conflict risk.
