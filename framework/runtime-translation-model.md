# Runtime Translation Model

Runtime translation converts canonical ATLAS concepts into the conventions of a
specific AI engineering runtime.

## Translation layers

### Identity translation

Maps canonical agents to runtime-specific role definitions.

### Invocation translation

Maps commands and workflows to runtime-supported entry points.

### Tool translation

Maps abstract capabilities to concrete runtime tools.

### Governance translation

Preserves contracts, review gates, escalation, and evidence requirements.

### Context translation

Preserves project memory, source-of-truth documents, and retrieval behavior.

## Translation rule

Translation may change syntax and structure, but not semantic responsibility.
