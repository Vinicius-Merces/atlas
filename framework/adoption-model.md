# Adoption Model

ATLAS adoption should improve delivery without forcing every project into the
same shape.

## Adoption stages

### 1. Discover

Map the repository, architecture, ownership, workflows, and current pain points.

### 2. Select

Choose the ATLAS components that solve current needs.

### 3. Initialize

Add memory, rules, contracts, orchestrator, and selected workflows.

### 4. Integrate

Connect ATLAS to existing CI, release, documentation, and runtime conventions.

### 5. Validate

Confirm that commands, agents, workflows, and reviews are usable.

### 6. Expand

Add specialists, skills, blueprints, and governance only when justified.

### 7. Measure

Track friction, quality, cycle time, defects, adoption, and operational outcomes.

## Adoption principle

Start with the smallest useful operating system. Expand through evidence rather
than installing complexity for its own sake.
