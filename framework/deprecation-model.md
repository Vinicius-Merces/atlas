# Deprecation Model

Deprecation is a managed transition from a supported asset to a preferred
replacement or retirement state.

## Deprecation lifecycle

1. Proposed
2. Announced
3. Deprecated
4. Migration available
5. Removal scheduled
6. Removed
7. Archived

## Required deprecation metadata

- Asset
- Reason
- Replacement
- Migration path
- Announced version
- Removal version
- Owner
- Known impact
- Review date

## Deprecation principles

- Avoid silent removal.
- Provide migration guidance.
- Preserve traceability.
- Allow sufficient transition time.
- Validate replacement readiness.
- Update examples, blueprints, adapters, and documentation.
