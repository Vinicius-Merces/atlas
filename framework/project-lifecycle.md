# Project Lifecycle

## 1. Discovery

Understand the user, business objective, constraints, systems, and risks.

## 2. Architecture

Define boundaries, contracts, data ownership, integration patterns, and
quality requirements.

## 3. Planning

Break work into testable increments with explicit ownership and acceptance
criteria.

## 4. Implementation

Execute within declared scope using existing components and skills where
possible.

## 5. Validation

Test functionality, integration, security, accessibility, performance, and
operational behavior.

## 6. Release

Prepare deployment, migration, monitoring, rollback, and communication.

## 7. Operations

Observe behavior, respond to failures, and protect service continuity.

## 8. Evolution

Use production evidence and business learning to guide future improvements.
