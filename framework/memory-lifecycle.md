# Memory Lifecycle

## 1. Candidate

A potentially reusable fact or rule is identified.

## 2. Validation

The candidate is checked against the source of truth.

## 3. Classification

It is assigned to the appropriate memory category.

## 4. Publication

The memory is written into a canonical document with ownership and review
metadata.

## 5. Consumption

Agents use the memory during relevant tasks.

## 6. Review

The memory is periodically or event-trigger reviewed.

## 7. Update or retirement

Stale or superseded knowledge is corrected, archived, or removed.

## Promotion rule

Temporary observations must not become persistent memory without validation.

## Retirement triggers

- Architecture replacement
- Contract migration
- Product policy change
- Integration removal
- Security model change
- Brand redesign
