# Release Governance Checklist

## Scope

- [ ] Version confirmed
- [ ] Changelog updated
- [ ] Release scope frozen

## Quality

- [ ] Mandatory tests pass
- [ ] Required reviews approved
- [ ] Known risks documented

## Operations

- [ ] Deployment plan ready
- [ ] Monitoring ready
- [ ] Rollback ready
- [ ] Migrations reviewed

## Communication

- [ ] Release notes prepared
- [ ] Stakeholders informed
- [ ] Incident ownership identified

## Decision

- [ ] Go
- [ ] Conditional go
- [ ] No-go
