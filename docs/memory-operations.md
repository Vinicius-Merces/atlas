# Memory Operations Guide

## Creating memory

1. Identify a stable fact or rule.
2. Verify its source of truth.
3. Select the correct memory category.
4. Add ownership and review metadata.
5. Link related ADRs and contracts.
6. Avoid duplication.

## Updating memory

- Change the canonical file.
- Remove contradictory guidance.
- Record material architecture changes in an ADR.
- Update references when paths or systems change.

## Reviewing memory

Review memory when:

- A major release ships.
- An integration changes.
- Architecture changes.
- Security policy changes.
- A conflict is discovered.
- The scheduled review date arrives.

## Memory hygiene

Good memory is concise, canonical, actionable, and current.
