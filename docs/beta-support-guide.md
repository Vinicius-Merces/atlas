# Beta Support Guide

## Canonical runtime

Claude Code is the canonical beta-supported runtime.

## Experimental adapters

Codex, Gemini, and Cursor mappings are available for evaluation but may require
manual adjustment.

## Stability boundary

Core contracts and canonical paths receive compatibility protection during the
beta line.

## Reporting issues

Include framework version, runtime, project type, reproduction, expected
behavior, and observed behavior.

## Upgrading

Review release notes, migration guidance, compatibility matrix, deprecations,
and known limitations before replacing cumulative files.
