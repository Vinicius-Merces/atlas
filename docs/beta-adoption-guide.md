# Beta Adoption Guide

## Appropriate use

Beta is suitable for teams willing to validate workflows and report friction.

## Recommended path

1. Use the Claude Code runtime.
2. Start with project bootstrap and memory.
3. Select only relevant agents and workflows.
4. Enable validation scripts.
5. Use blueprints as starting points.
6. Record project-specific decisions separately.
7. Test upgrades before merging.

## Avoid blind installation

ATLAS should be adapted proportionally to project needs.
