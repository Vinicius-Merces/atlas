# Manual Continuity Refresh Guide

After your manual deploy:

1. Confirm `VERSION`.
2. Copy new and replacement files.
3. Run source-of-truth validation if desired.
4. Generate or update the project brief.
5. Create a session brief.
6. Build the resume packet.
7. Audit memory drift.
8. Review the generated proposal before changing memory.

All scripts are optional helpers. Manual file review remains supported.
