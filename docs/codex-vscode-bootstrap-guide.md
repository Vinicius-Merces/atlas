# Codex VS Code Bootstrap Guide

After cloning the repository:

1. Open the repository root in VS Code.
2. Let Codex read `AGENTS.md`.
3. Ask Codex to read `.atlas/continuity/resume-packet.json`.
4. Read the referenced project brief, session brief, memory, ADRs, and tasks.
5. Validate repository status before editing.
6. Continue from the recorded next action.

The previous ChatGPT conversation is not required when the repository continuity
artifacts are current.
