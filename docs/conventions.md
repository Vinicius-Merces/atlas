# Repository Conventions

## File naming

Use lowercase kebab-case for Markdown and configuration documents.

Examples:

- `frontend-engineer.md`
- `quality-model.md`
- `ADR-002-agent-contracts.md`

## Branch naming

- `feature/<name>`
- `fix/<name>`
- `docs/<name>`
- `release/<version>`

## Commit prefixes

- `feat:`
- `fix:`
- `docs:`
- `refactor:`
- `perf:`
- `test:`
- `chore:`

## Documentation style

- Start with purpose.
- Use explicit headings.
- State constraints and consequences.
- Avoid duplicated guidance.
- Cross-reference canonical documents.

## Versioning

ATLAS follows semantic versioning.

- Patch: corrections and backward-compatible improvements
- Minor: new capabilities
- Major: incompatible structural changes
