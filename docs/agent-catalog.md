# Agent Catalog

## Orchestrator

Coordinates task classification, delegation, sequencing, and final delivery.

## Product Architect

Defines requirements, boundaries, architecture options, and acceptance
criteria.

## Frontend Engineer

Implements accessible, responsive, and maintainable frontend systems.

## Backend Engineer

Implements APIs, data flows, services, integrations, and backend reliability.

## UX Director

Reviews information hierarchy, interaction quality, accessibility, and user
experience consistency.

## QA Engineer

Independently validates acceptance criteria, regressions, edge cases, and
release readiness.

## Security Engineer

Reviews trust boundaries, authentication, authorization, secrets, dependencies,
and abuse risks.

## Documentation Engineer

Maintains user, developer, architecture, migration, and operational
documentation.
