# Platform Guide

## Build around recurring friction

A platform capability should remove repeated work across multiple teams or
systems.

## Offer a golden path

The supported route should be easy to discover, safe by default, observable,
and documented.

## Preserve product autonomy

Platforms should centralize reusable infrastructure, not product-specific
decisions.

## Measure the platform

Track adoption, success rate, developer effort, reliability, support burden,
and escape-hatch usage.
