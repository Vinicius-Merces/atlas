# Performance Budget Analysis Skill

## Purpose

Define and evaluate measurable performance limits.

## Inputs

- User journey
- Current baseline
- Platform constraints
- Business criticality

## Possible budgets

- Response latency
- Error rate
- Throughput
- Memory use
- CPU use
- Bundle size
- Startup time
- Largest Contentful Paint
- Interaction latency
- Database query duration

## Output

- Baseline
- Proposed budgets
- Measurement method
- Regression threshold
- Blocking threshold
- Review cadence
