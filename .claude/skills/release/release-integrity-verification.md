# Release Integrity Verification Skill

## Purpose

Verify that a release artifact is complete, consistent, and traceable.

## Checks

- Version consistency
- Changelog entry
- Registry validity
- Required files
- Adapter inclusion
- Manifest completeness
- Archive integrity
- Checksums
- Validation evidence
- Known limitations

## Output

- Integrity result
- Blocking failures
- Warnings
- Artifact metadata
- Release recommendation
