# Knowledge Graph Synthesis Skill

## Purpose

Convert distributed project documents into a linked and traceable knowledge
structure.

## Procedure

1. Identify canonical entities.
2. Extract owners, systems, decisions, contracts, and risks.
3. Normalize names and identifiers.
4. Create explicit relationships.
5. Link sources and provenance.
6. Identify contradictions and missing ownership.
7. Produce indexes and navigation notes.

## Output

- Entity catalog
- Relationship map
- Knowledge gaps
- Conflicts
- Suggested links
- Obsidian-compatible index notes
