# Entity Authority Mapping

## Procedure
1. Inventory entities that materially affect a decision: organization, offer, product, person, location, policy, proof, and published content.
2. For each, record canonical name, identifier/URL, owner, claim set, source evidence, update cadence, locale equivalents, and whether it is public.
3. Detect conflicting facts across pages, CMS, metadata, schema, feeds, profiles, and sales collateral.
4. Mark unsupported claims for removal, qualification, or evidence collection. Do not promote a claim merely because it would be useful for SEO/GEO.
5. Define the canonical source and the rendered page that explains each material entity to a human.

## Output
A traceable entity ledger: entity → canonical URL → factual claims → evidence/owner → freshness → conflicts → remediation.

## Guardrails
No invented expertise, customer proof, certifications, availability, reviews, or third-party references. Private operational data is not public GEO material by default.
