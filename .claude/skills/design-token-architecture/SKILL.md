# Design Token Architecture Skill

## Purpose

Design semantic, scalable tokens for multi-theme and multi-platform products.

## Inputs

- Brand foundations
- Supported themes
- Platforms
- Existing component system

## Procedure

1. Inventory raw design values.
2. Separate primitive and semantic tokens.
3. Define naming conventions.
4. Map semantic roles to primitives.
5. Define theme overrides.
6. Define platform transformations.
7. Validate contrast and state coverage.
8. Define versioning and migration.

## Output

- Token hierarchy
- Naming model
- Theme model
- Platform mapping
- Accessibility constraints
- Migration plan
