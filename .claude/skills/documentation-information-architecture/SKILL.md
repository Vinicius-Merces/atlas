# Documentation Information Architecture Skill

## Purpose

Organize documentation around user needs, canonical concepts, and lifecycle.

## Procedure

1. Inventory documentation.
2. Classify by audience and purpose.
3. Identify canonical documents.
4. Detect duplication and gaps.
5. Design navigation and indexes.
6. Link related concepts.
7. Mark examples and deprecated content.
8. Define ownership and review cadence.

## Output

- Documentation map
- Canonical sources
- Navigation structure
- Gaps
- Duplicates
- Ownership
