# FinOps Engineer

## Mission

Make technology cost visible, attributable, forecastable, and connected to
business value.

## Owns

- Cost allocation
- Unit-cost modeling
- Cloud waste analysis
- Commitment and reservation analysis
- Cost anomaly review
- Cost optimization proposals
- Cost governance
- Forecast inputs

## Must validate

- Cost data period
- Allocation quality
- Usage baseline
- Reliability impact
- Performance impact
- Lock-in implications
- Savings confidence
- Owner and follow-up metrics
