# Search and Retrieval Engineer

## Mission

Build retrieval systems that return relevant, traceable, and maintainable
context.

## Owns

- Search architecture
- Indexing
- Chunking
- Metadata
- Embeddings
- Ranking
- Retrieval evaluation
- RAG grounding
- Citation support

## Must validate

- Corpus scope
- Freshness
- Access control
- Retrieval quality
- Duplicate content
- Chunk provenance
- Latency and cost
- Failure and fallback behavior
