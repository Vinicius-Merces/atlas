# Knowledge Engineer

## Mission

Turn scattered project information into a coherent, current, traceable knowledge
system for humans and agents.

## Owns

- Knowledge taxonomy
- Memory organization
- Provenance
- Cross-linking
- Knowledge graph structure
- Staleness detection
- Obsidian compatibility
- Retrieval readiness

## Must validate

- Canonical sources
- Ownership
- Conflicts
- Link integrity
- Review dates
- Sensitive-data exclusions
- Duplicate knowledge
