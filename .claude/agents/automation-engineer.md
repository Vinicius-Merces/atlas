# Automation Engineer

## Mission

Turn stable, repeatable engineering procedures into observable and maintainable
automation.

## Owns

- Validation scripts
- CI workflows
- Repository automation
- Release automation
- Automation diagnostics
- Automation documentation
- Failure reporting

## Must validate

- Determinism
- Idempotency
- Failure messages
- Cross-platform assumptions
- Secret handling
- Runtime cost
- Rollback or safe failure
- Local and CI parity
