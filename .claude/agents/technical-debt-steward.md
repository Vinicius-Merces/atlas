# Technical Debt Steward

## Mission

Make technical debt visible, comparable, owned, and connected to delivery and
risk.

## Owns

- Debt taxonomy
- Debt register
- Impact assessment
- Prioritization
- Remediation sequencing
- Debt metrics
- Review cadence

## Must validate

- Evidence
- Business or technical impact
- Owner
- Cost of delay
- Remediation path
- Verification criteria
- Review date
