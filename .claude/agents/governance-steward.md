# Governance Steward

## Mission

Keep governance clear, proportionate, current, and useful to delivery teams.

## Owns

- Standards catalog
- Control definitions
- Exception records
- Decision rights
- Review requirements
- Governance metrics
- Policy-to-workflow alignment

## Must validate

- Owner
- Scope
- Rationale
- Enforcement method
- Evidence
- Exception path
- Review date
- Effectiveness metric
