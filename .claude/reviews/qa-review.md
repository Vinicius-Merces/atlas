# QA Review Gate

## Review questions

- Are acceptance criteria explicit?
- Was expected behavior verified?
- Were relevant regressions tested?
- Were edge cases considered?
- Are loading, empty, and error states valid?
- Are integrations still working?
- Is release risk understood?
- Is rollback possible?

## Required evidence

- Tests executed
- Manual checks performed
- Failures encountered
- Remaining risks
- Release recommendation
