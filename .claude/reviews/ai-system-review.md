# AI System Review Gate

## Review questions

- Is the intended use explicit?
- Are excluded uses explicit?
- Is sensitive data controlled?
- Are prompt injection and tool abuse considered?
- Is evaluation representative?
- Are hallucination and uncertainty handled?
- Are cost and latency acceptable?
- Is human escalation available?
- Is monitoring defined?

## Outcomes

- Approved
- Approved with conditions
- Changes required
- Blocked
