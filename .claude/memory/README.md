# Project Memory

Store stable, reusable project knowledge here.

Recommended files:

- `business.md`
- `architecture.md`
- `integrations.md`
- `brand.md`
- `security.md`
- `decisions.md`

Do not store:

- Secrets
- Access tokens
- Temporary logs
- Unverified assumptions
- Short-lived task notes

Memory should have a clear owner, source, and review cadence.
