# Global Rules

1. Understand before modifying.
2. Preserve unrelated behavior.
3. Search for existing solutions before creating new ones.
4. Never expose secrets.
5. Do not silently change public contracts.
6. Keep changes incremental and reviewable.
7. Validate affected integrations.
8. Document architecture-impacting changes.
9. Respect accessibility and reduced-motion preferences.
10. Report uncertainty and incomplete validation honestly.
