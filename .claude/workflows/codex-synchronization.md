# Codex Synchronization Workflow

## Trigger

Canonical agents, commands, skills, workflows, reviews, or contracts change.

## Sequence

1. Identify changed canonical assets.
2. Run Codex runtime generation.
3. Update capability mappings.
4. Update unsupported feature notes.
5. Validate Codex manifest.
6. Run Codex tests.
7. Run runtime parity review.
8. Publish synchronization evidence.
