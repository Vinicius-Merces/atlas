# Knowledge Synchronization Workflow

## Trigger

Project behavior, architecture, ownership, or source-of-truth documentation
changes.

## Sequence

1. Identify changed facts and affected notes.
2. Verify source of truth.
3. Update canonical memory or ADR.
4. Update links and indexes.
5. Remove stale or duplicate guidance.
6. Validate Obsidian links and metadata.
7. Record review date and owner.
8. Confirm retrieval indexes should refresh.

## Completion criteria

- Canonical knowledge updated
- Conflicts resolved
- Links valid
- Provenance preserved
