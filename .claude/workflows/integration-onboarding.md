# Integration Onboarding Workflow

## Trigger

A new internal or external system integration is introduced.

## Sequence

1. Identify provider, consumer, and owners.
2. Map contract and environments.
3. Review security and privacy.
4. Define failure, retry, and idempotency behavior.
5. Implement adapter and validation.
6. Add integration tests.
7. Add observability and alerts.
8. Document support and escalation.
9. Validate sandbox and production behavior.
