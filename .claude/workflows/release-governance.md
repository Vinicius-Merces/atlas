# Release Governance Workflow

## Trigger

A release candidate is proposed.

## Sequence

1. Freeze intended scope.
2. Verify version and changelog.
3. Collect mandatory review outcomes.
4. Confirm migrations, monitoring, and rollback.
5. Confirm known-risk acceptance.
6. Prepare release notes and communication.
7. Make go/no-go decision.
8. Execute rollout.
9. Validate production behavior.
10. Close or roll back release.
