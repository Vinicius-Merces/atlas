# Project Bootstrap Workflow

## Trigger

A new or previously unmanaged project adopts ATLAS.

## Sequence

1. Map repository and runtime.
2. Identify applications, packages, services, and integrations.
3. Create project memory index.
4. Capture business and architecture memory.
5. Identify required agents and workflows.
6. Establish build, test, and release commands.
7. Define initial quality gates.
8. Create repository and architecture maps.
9. Record known risks and gaps.
10. Validate onboarding from a clean environment.

## Completion criteria

- Repository map exists
- Critical commands are documented
- Ownership is visible
- Memory foundation exists
- Risks are recorded
- Initial workflows are usable
