# Blueprint Instantiation Workflow

## Trigger

A project is initialized from an ATLAS blueprint.

## Sequence

1. Select blueprint.
2. Confirm assumptions.
3. Adapt architecture and memory requirements.
4. Copy starter structure.
5. Configure agents and workflows.
6. Add project-specific constraints.
7. Validate build, test, release, and documentation.
8. Remove irrelevant placeholders.
9. Record deviations.
