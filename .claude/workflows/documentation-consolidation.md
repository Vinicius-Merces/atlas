# Documentation Consolidation Workflow

## Trigger

Documentation becomes fragmented, duplicated, or difficult to navigate.

## Sequence

1. Inventory documents.
2. Identify canonical sources.
3. Map audiences and tasks.
4. Merge or retire duplicates.
5. Create indexes.
6. Repair cross-links.
7. Mark deprecated guidance.
8. Validate commands and paths.
9. Assign ownership.
