# Default Workflow

## 1. Understand

Resolve the desired outcome and acceptance criteria.

## 2. Inspect

Read relevant code, memory, contracts, and existing patterns.

## 3. Plan

Define scope, sequence, risks, and validation.

## 4. Execute

Make the smallest coherent change.

## 5. Validate

Run relevant tests and inspect affected behavior.

## 6. Review

Check quality, contracts, security, and regressions.

## 7. Document

Update documentation and decisions when required.

## 8. Deliver

Summarize changes, validation, and remaining risks.
