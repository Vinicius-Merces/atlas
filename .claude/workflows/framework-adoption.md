# Framework Adoption Workflow

## Trigger

A new or existing project adopts ATLAS.

## Sequence

1. Run project adoption assessment.
2. Select minimum useful components.
3. Create repository and architecture maps.
4. Initialize memory.
5. Add orchestrator and relevant agents.
6. Add core workflows and reviews.
7. Integrate validation and CI.
8. Validate representative tasks.
9. Train contributors through documentation.
10. Measure adoption outcomes.
