# Feature Delivery Workflow

## Trigger

A new capability or meaningful behavior change is requested.

## Sequence

1. Orchestrator classifies scope and risk.
2. Product Architect defines requirements and acceptance criteria.
3. Relevant implementation agents inspect existing patterns.
4. Architecture review is required for shared contracts or data changes.
5. Implementation proceeds incrementally.
6. Security and UX review run when applicable.
7. QA validates acceptance criteria and regressions.
8. Documentation Engineer updates affected documentation.
9. Orchestrator consolidates evidence and delivery notes.

## Completion criteria

- Acceptance criteria satisfied
- Mandatory reviews approved
- Tests or validation evidence available
- Documentation updated
- Remaining risks disclosed
