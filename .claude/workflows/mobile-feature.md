# Mobile Feature Workflow

## Trigger

A feature changes mobile application behavior or native platform integration.

## Sequence

1. Define supported platforms and OS versions.
2. Review navigation, lifecycle, and state impact.
3. Review permissions and privacy.
4. Implement platform-appropriate behavior.
5. Validate offline and poor-network states.
6. Validate accessibility and device compatibility.
7. Run regression and performance checks.
8. Prepare store-facing documentation if required.
