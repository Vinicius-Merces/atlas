# Beta Release Preparation Workflow

## Trigger

The alpha line is ready to produce a beta release candidate.

## Sequence

1. Freeze beta scope.
2. Stabilize core contracts.
3. Validate registry and schemas.
4. Run smoke tests.
5. Review compatibility matrix.
6. Review deprecations.
7. Review blueprints and examples.
8. Validate migration and adoption paths.
9. Publish known limitations.
10. Build release candidate artifact.
11. Run beta readiness review.
