# Localization Delivery Workflow

## Trigger

A feature ships in multiple locales or changes translatable content.

## Sequence

1. Run localization readiness assessment.
2. Externalize and contextualize strings.
3. Validate locale formatting.
4. Prepare translation resources.
5. Review text expansion and bidirectional behavior.
6. Perform locale QA.
7. Validate fallback behavior.
8. Release and monitor translation issues.
