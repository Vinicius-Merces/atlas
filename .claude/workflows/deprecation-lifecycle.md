# Deprecation Lifecycle Workflow

## Trigger

An ATLAS asset should be replaced or retired.

## Sequence

1. Create deprecation proposal.
2. Identify consumers.
3. Validate replacement.
4. Publish migration guidance.
5. Announce deprecation version.
6. Add warnings and compatibility tests.
7. Review adoption.
8. Remove only after scheduled version.
9. Archive references and validate package.
