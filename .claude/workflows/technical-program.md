# Technical Program Workflow

## Trigger

A technical objective spans multiple teams, systems, releases, or workstreams.

## Sequence

1. Define outcome and scope.
2. Identify sponsors, owners, and stakeholders.
3. Create workstreams and milestones.
4. Map dependencies and critical path.
5. Create risk and decision registers.
6. Define status and evidence expectations.
7. Coordinate delivery and escalation.
8. Validate milestone outcomes.
9. Close program and transfer remaining ownership.

## Rules

- Status must reflect evidence, not optimism.
- Dependencies require named owners.
- Decisions and accepted risks remain traceable.
