# /atlas-incident

## Purpose

Coordinate incident triage, stabilization, recovery, and reporting.

## Inputs

- Symptoms
- Impact
- Environment
- Start time
- Available telemetry

## Execution

1. Invoke incident triage.
2. Assign reliability and domain owners.
3. Classify severity.
4. Define containment action.
5. Track recovery evidence.
6. Prepare incident report and follow-up actions.

## Output

- Severity
- Impact
- Timeline
- Current status
- Mitigation
- Remaining risk
- Follow-up actions
