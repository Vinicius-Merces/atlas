# /atlas-test

## Purpose

Create or evaluate a risk-based testing strategy.

## Inputs

- Change scope
- Acceptance criteria
- Architecture
- Existing tests

## Execution

1. Run test strategy design.
2. Identify critical paths and risk.
3. Select test layers.
4. Define automation and manual checks.
5. Define release exit criteria.

## Output

- Test matrix
- Automation plan
- Manual validation
- Gaps
- Exit criteria
