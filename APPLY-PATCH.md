# Apply ATLAS Patch Manually

## Required base

`0.1.0-beta.8`

## Target

`0.1.0-beta.9`

## Manual deployment

1. Extract this ZIP.
2. Copy all included folders and files into the repository root.
3. When prompted, replace existing files.
4. Add the new files normally.
5. Delete only paths listed in `FILES-TO-DELETE.md`.
6. Confirm that the repository `VERSION` now shows `0.1.0-beta.9`.

The scripts included in this patch are optional validation helpers. They are not
required to apply the update.
