# Marketplace & Ecommerce Blueprint

## Best for

Catalog, marketplace, booking and commerce experiences with discovery, inventory/availability, checkout, payments and transactional communication.

## Default capability path

`saas-from-brief-delivery` or `site-from-brief-delivery` according to account model, plus search, forms, files, payments, webhooks, email/notifications, rate controls, analytics and structured data.

## Non-negotiable gates

Server-authoritative price/availability, payment reconciliation, search/filter quality, conversion/accessibility, tenant/seller boundaries when applicable and public-web assurance.
