# Premium Marketing Site Blueprint

## Best for

Brand, service, campaign and conversion sites where distinctive art direction and measurable acquisition matter.

## Default capability path

`site-from-brief-delivery` with Frontend Craft mandatory. Add CMS, forms, analytics, conversion, motion/3D, structured data and integrations only as the brief requires.

## Non-negotiable gates

Visual thesis, responsive/accessibility evidence, browser validation, performance, technical SEO, content discoverability, supply-chain review, and independent Frontend Craft approval.
