# Content Site Blueprint

## Best for

Blogs, editorial sites, knowledge hubs, documentation, portfolios and content-rich public properties.

## Default capability path

`site-from-brief-delivery` plus `cms-content-modeling`, `content-discoverability-review`, `seo-technical-audit`, `structured-data-validation`, and `application-search-design` when discovery volume justifies it.

## Non-negotiable gates

Editorial lifecycle, truthful metadata, semantic/rendered content, internal discovery, accessibility, performance and browser evidence.
