# Subscription SaaS Blueprint

## Best for

Multi-tenant products with authenticated dashboards, plans/subscriptions, entitlements and recurring operational workflows.

## Default capability path

`saas-from-brief-delivery` plus authentication, authorization, multitenancy/RLS, payments, schema, background jobs, notifications, audit/admin operations, analytics and feature rollout as applicable.

## Non-negotiable gates

Cross-tenant negative evidence, authoritative payment/entitlement reconciliation, premium responsive frontend, provider failure handling and production trust review.
