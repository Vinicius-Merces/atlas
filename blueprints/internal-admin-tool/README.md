# Internal Admin Tool Blueprint

## Best for

Back-office systems, support consoles, operational CRUD, approval workflows and internal business applications.

## Default capability path

`saas-from-brief-delivery` with `admin-operations-surface`, `audit-log-design`, `form-mutation-design`, authorization, schema and import/export as applicable.

## Non-negotiable gates

Least-privilege actions, explicit tenant/customer context, consequential-action audit evidence, accessible efficient UI, browser validation and rollback/recovery for dangerous operations.
