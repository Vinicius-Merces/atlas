# ATLAS AI Engineering Framework

**Version:** `0.1.0-alpha.4`  
**Status:** Foundation / Specialist Runtime

ATLAS is an AI engineering framework for coordinating software development
through specialized agents, persistent memory, reusable skills, explicit
workflows, quality gates, and architecture governance.

ATLAS is not a prompt collection. It is an operating model for AI-assisted
engineering.

## Core flow

```text
User request
    ↓
Context engine
    ↓
Orchestrator
    ↓
Specialist agents
    ↓
Reviews and quality gates
    ↓
Documentation
    ↓
Delivery
```

## What alpha.4 adds

- First specialist agent set
- Skill contract
- Review contract
- Command contract
- Feature delivery workflow
- Bug-fix workflow
- Architecture and QA review gates
- Agent registry
- Runtime manifest

## Current specialist agents

- Product Architect
- Frontend Engineer
- Backend Engineer
- UX Director
- QA Engineer
- Security Engineer
- Documentation Engineer

## Guiding principle

> Knowledge should be reusable, execution should be bounded, and important
> decisions should remain traceable.
