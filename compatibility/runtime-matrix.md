# Runtime Compatibility Matrix

| Runtime | Status | Adapter | Notes |
|---|---|---|---|
| Claude Code | Beta-supported | `.claude/` | Canonical source runtime |

## Compatibility policy

- Beta-supported runtimes have independent validation.
- Runtime syntax may differ while semantics remain stable.
- Experimental runtimes may require manual translation.
