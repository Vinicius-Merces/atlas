# Codex Support Policy

## Support state

Codex is a supported compatibility runtime in ATLAS `0.1.0`. Its support
graduated after the beta and release-candidate validation cycles.

## Supported areas

- Role-based agent mapping
- Command intent
- Workflow sequencing
- Review gates
- Shared contracts
- Shared memory
- Package and contract validation
- Codex runtime tests

## Limitations

- Tool names and invocation differ from Claude Code.
- Some runtime orchestration may remain manual.
- Canonical definitions remain under the shared ATLAS framework and `.claude/`
  implementation.

## Compatibility commitment

Codex mappings preserve stable ATLAS semantics throughout the `0.1.x` line.
