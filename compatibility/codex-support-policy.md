# Codex Support Policy

## Support state

Codex is beta-supported as a compatibility runtime in ATLAS `0.1.0-beta.2`.

## Supported areas

- Role-based agent mapping
- Command intent
- Workflow sequencing
- Review gates
- Shared contracts
- Shared memory
- Package and contract validation
- Codex runtime tests

## Limitations

- Tool names and invocation differ from Claude Code.
- Some runtime orchestration may remain manual.
- Canonical definitions remain under the shared ATLAS framework and `.claude/`
  implementation.

## Compatibility commitment

Codex mappings will preserve stable ATLAS semantics throughout the beta line.
