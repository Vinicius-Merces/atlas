# ATLAS Obsidian Vault

Open the `obsidian/` directory as an Obsidian vault or copy its contents into an
existing project vault.

The vault is intentionally plain Markdown and remains compatible with GitHub,
text editors, and retrieval pipelines.

For adopted product repositories, generate their own self-contained view with
`project_memory.py`; see [Project-local memory](../docs/project-local-memory-guide.md).
Upstream indexes are framework knowledge, not product memory.
