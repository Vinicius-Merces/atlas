# Asteria Residences

P4 diagnostic calibration build for the `premium-marketing-site` fixture.

This implementation remains isolated on `bench/p4-asteria-calibration-gpt-5-6-sol` and must not be reused by the Codex or Claude Code target runs.

Stack: authored HTML, CSS and JavaScript plus a Python HTTP service. Browser evidence is collected with Playwright/Chromium.

The calibration is localhost-only, so it does not claim the production-domain benchmark check.
