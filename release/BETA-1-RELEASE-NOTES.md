# ATLAS 0.1.0-beta.1 Release Notes

ATLAS has entered its first beta.

## What beta means

Core contracts and canonical paths now have an explicit compatibility
commitment for the beta line.

## Supported

- Canonical Claude Code runtime
- Core agent, memory, workflow, skill, review, and command contracts
- Package, registry, smoke, and contract validation
- Adoption and migration workflows

## Experimental

- Codex adapter
- Gemini adapter
- Cursor adapter

## Feedback priorities

- Contract clarity
- Adoption friction
- Runtime adapter behavior
- Upgrade reliability
- Blueprint usefulness
- Documentation navigation
