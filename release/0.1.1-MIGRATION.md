# Migrating ATLAS 0.1.0 to 0.1.1

## Supported base

The incremental package targets the published `v0.1.0` source:

```text
from_version: 0.1.0
to_version: 0.1.1
base_commit: ce18265b0ece839a862240bb1a170e7532c7b7bd
```

If the installed `VERSION` is not exactly `0.1.0`, stop and use the documented
intermediate upgrade or cumulative recovery path.

## Before applying

1. Preserve the current repository or make a recoverable backup.
2. Extract the incremental ZIP.
3. Verify its external `.sha256` and `.manifest.json`.
4. Run:

   ```bash
   python scripts/manual_deploy_preflight.py \
     --installed-root <installed-atlas> \
     --patch-root <extracted-versioned-patch-root>
   ```

5. Stop on any existing add target, missing replace/delete target, or
   `base_sha256` mismatch. These indicate project-owned or unexpected state
   that must be merged explicitly.

## Applying manually

- Copy only entries in `FILES-TO-ADD.md`.
- Replace only entries in `FILES-TO-REPLACE.md`.
- Map `CLAUDE-DIRECTORY/...` to `.claude/...`.
- Delete only entries in `FILES-TO-DELETE.md`.
- Absence from the patch never authorizes deletion.
- The skill migration intentionally deletes legacy
  `.claude/skills/<category>/<name>.md` files and adds
  `.claude/skills/<name>/SKILL.md`.
- Generated Codex wrappers are added under `.agents/skills/`.

No application script is required. The preflight script is the recommended
conflict and integrity check when Python is available.

## Validation

After copying:

```bash
python scripts/validate_all.py --profile full
python scripts/sync_native_skills.py --check
python scripts/sync_codex_adapter.py --check
python scripts/detect_runtime_drift.py
```

Confirm `VERSION` is `0.1.1`. Record significant manual deployments with
`record_manual_deploy.py`; successful status requires the passed preflight
report and at least one validation statement.

## Existing product repositories

Do not copy the cumulative package over an occupied project. First run:

```bash
python scripts/plan_project_adoption.py \
  --target-root <existing-project> \
  --output adoption-plan.json \
  --markdown-output adoption-plan.md
```

Merge project-owned `README.md`, `LICENSE`, `AGENTS.md`, `CLAUDE.md`,
`VERSION`, `.gitignore`, `.github/`, and `.claude/memory/`. Review every other
collision before copying.

## Rollback

Restore the preserved 0.1.0 repository or extract the validated 0.1.1 recovery
package into a clean recovery location. Do not infer rollback deletions from
file absence.
