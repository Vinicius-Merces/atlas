# Migration to 0.1.0-beta.10

Apply this incremental patch manually only over `0.1.0-beta.9`.

## Manual procedure

1. Extract the ZIP.
2. Copy all included folders and files to the repository root.
3. Replace files listed in `FILES-TO-REPLACE.md`.
4. Add files listed in `FILES-TO-ADD.md`.
5. Delete only paths listed in `FILES-TO-DELETE.md`.
6. Confirm `VERSION` is `0.1.0-beta.10`.

The included scripts are optional helpers. Manual deployment does not depend on
them.
