# Migration from 0.1.0-beta.11 to 0.1.0

Stable `0.1.0` preserves the canonical paths and core contract semantics of the
beta and RC lines. The supported runtimes are Claude Code and Codex; Gemini and
Cursor remain experimental.

## Manual incremental upgrade

1. Confirm the installed `VERSION` is exactly `0.1.0-beta.11`.
2. Preserve the installed repository or the beta.11 cumulative package.
3. Verify the external SHA-256 of the stable incremental ZIP.
4. Extract the versioned patch root.
5. Copy every file listed in `FILES-TO-ADD.md`.
6. Copy and overwrite every file listed in `FILES-TO-REPLACE.md`.
7. Map `CLAUDE-DIRECTORY/...` to `.claude/...`.
8. Remove only paths explicitly listed in `FILES-TO-DELETE.md`.
9. Confirm `VERSION` is `0.1.0`.
10. Optionally run the repository validators and test suite.

No script is required to apply the patch. A missing path in the archive never
authorizes deletion.

## RC installations

Installations already on `0.1.0-rc.1` may use the stable cumulative package.
Its versioned root can be copied over the RC installation while preserving
project-specific memory and customizations.

## Rollback

Restore the preserved beta.11 installation or use the validated stable recovery
package. Do not infer deletions from archive absence.
