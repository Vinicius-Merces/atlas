# Migration to 0.1.0-beta.9

Apply this patch manually only over `0.1.0-beta.8`.

## Manual procedure

1. Extract the package.
2. Copy its folders and files to the repository root.
3. Allow files listed in `FILES-TO-REPLACE.md` to be replaced.
4. Add files listed in `FILES-TO-ADD.md`.
5. Remove only paths listed in `FILES-TO-DELETE.md`.
6. Confirm `VERSION` is `0.1.0-beta.9`.

Validation scripts are optional after manual deployment.
