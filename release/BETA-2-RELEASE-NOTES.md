# ATLAS 0.1.0-beta.2 Release Notes

## Headline

ATLAS now supports Claude Code and Codex as beta runtimes.

## Claude Code

Remains the canonical source runtime.

## Codex

Now includes functional role, command, workflow, review, skill, manifest, and
validation structures.

## Compatibility

Both runtimes use the same contracts, memory, framework models, documentation,
templates, and blueprints.

## Known differences

Tool invocation and execution ergonomics remain runtime-specific.
