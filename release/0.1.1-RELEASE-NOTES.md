# ATLAS 0.1.1 Release Notes

ATLAS 0.1.1 is a backward-compatible production-hardening release for the
stable `0.1.x` line. It preserves Claude Code as the canonical runtime and
Codex as a supported semantic-parity runtime.

## Production hardening

- All 394 registered agents, skills, workflows, reviews, commands, and memory
  assets satisfy their six canonical contracts with zero known violations.
- All 88 skills use Claude Code's native `SKILL.md` layout; synchronized
  Codex-native wrappers live under `.agents/skills/`.
- Root `CLAUDE.md` imports shared `AGENTS.md`, keeping one set of durable
  repository instructions.
- Lifecycle schemas reject wrong types, unknown states, malformed identifiers,
  and undeclared fields.
- Task routing, bounded context generation, and execution planning now include
  risk, runtime, affected paths, constraints, acceptance criteria, registered
  roles, skills, workflows, and reviews.
- The runtime golden path generates and validates the full portable artifact
  lifecycle while explicitly requiring an AI agent or human to execute real
  implementation work.

## Safe adoption and distribution

- The adoption planner classifies copy, identical, merge-required, and
  review-required paths without changing the target repository.
- Release builders enumerate tracked plus non-ignored untracked Git files,
  preserve deterministic archives, and reject symlinks.
- Incremental manifests include the exact base SHA-256 for every replacement
  and deletion.
- Manual preflight blocks an addition over an existing target, or a
  replacement/deletion whose installed content differs from the declared
  base.
- Cross-platform archive validation rejects traversal, absolute, drive-letter,
  UNC, backslash, duplicate, and mapping hazards.
- Deployment receipts default to `pending`; `applied` and `simulated` require
  a passed preflight report and concrete validation evidence.

## Assurance and evidence

- `scripts/validate_all.py` provides portable `quick`, `full`, and `release`
  profiles used locally and by CI.
- Validators for task envelopes, handoffs, and execution results use JSON
  Schema Draft 2020-12 and actionable error paths.
- Runtime conformance gates remain active under `python -O`.
- Audit bundles record source commit/repository state, protect their record
  index, validate JSON, and apply known evidence schemas in addition to hashes.

## Compatibility

The release is contract-compatible with 0.1.0. The native skill layout is a
repository migration handled explicitly by the incremental package: old paths
are listed for deletion and new paths for addition. Existing product
repositories must use the adoption planner and merge protected host files
instead of bulk copying a cumulative archive.

See `release/0.1.1-MIGRATION.md`, `release/0.1.1-VALIDATION.md`, and
`release/KNOWN-LIMITATIONS.md`.
