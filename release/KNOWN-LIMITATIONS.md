# Known Limitations

## Runtime adapters

Codex, Gemini, and Cursor adapters remain foundational and experimental.

## Automated schema coverage

Registry validation exists, but not every Markdown contract is machine-validated.

## Reference implementations

Blueprints and examples are structural starting points rather than complete production applications.

## Link validation

Internal Markdown links are only partially validated by smoke tests.

## Beta status

ATLAS remains in alpha until core contracts, compatibility, upgrade flow, and runtime behavior complete beta readiness review.
