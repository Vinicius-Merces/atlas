# Known Limitations

## Runtime adapters

Codex, Gemini, and Cursor adapters remain experimental.

## Contract automation

Core contracts are validated structurally, but semantic review still requires
human or agent judgment.

## Reference implementations

Blueprints are architecture starters, not production-complete applications.

## Link validation

Documentation link validation remains partial.

## Runtime-specific tool mapping

Target runtimes may expose different tools, permissions, or invocation models.

## Beta expectation

The beta line prioritizes compatibility and real-project feedback. Some
non-core capabilities may still evolve.
