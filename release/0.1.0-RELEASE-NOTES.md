# ATLAS 0.1.0 Release Notes

ATLAS `0.1.0` is the first stable release of the repository-native engineering
operating framework.

## Stable guarantees

- Claude Code remains the canonical supported runtime.
- Codex is a supported compatibility runtime with validated semantic parity.
- Core contract semantics and canonical paths are stable for the `0.1.x` line.
- Manual cumulative, incremental, and recovery deployment remains supported.
- Incremental `.claude/` payloads remain visible as `CLAUDE-DIRECTORY/`.
- Deletions remain explicit and never follow from archive absence.

## Distribution

- Deterministic cumulative package for clean installation
- Direct beta.11-to-stable incremental package
- Deterministic cumulative recovery package
- Internal content manifests and external SHA-256 files

## Compatibility

No approved breaking change is included. Gemini and Cursor remain experimental.
See the support policy, runtime matrix, deprecation policy, migration guide,
known limitations, and stable validation record.
